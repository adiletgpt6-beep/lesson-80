## Общие правила озвучки цитат
1. Арабский текст аятов и хадисов TTS **не произносит** (риск искажения); на доске — только ссылка («Бакара, 183»).
2. Перевод смысла на кыргызский — короткий, без кавычек «дословно»; формула «мааниси мындай».
3. Всё DROP не попадает в сценарий ни в каком виде. USE-CORR — только в исправленном виде.
4. Детали, которые устаз сказал, но которые не подтверждены (числа, имена, «научные» факты), — опускаются.
