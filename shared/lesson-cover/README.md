# Единая обложка уроков LESSON-80

Правило: [`OPENING_COVER_RULES.md`](../../OPENING_COVER_RULES.md) (main).

- `LessonCover.tsx` — **канонический** параметризованный компонент Remotion (только `react` + `remotion`). Меняются только `number` и `topic`; фон, орнамент, цвета, шрифт, размеры одинаковы для всех 80 уроков. Названия проекта нет.
- `COVER_FRAMES = 90` (ровно 3,00 с при 30 fps, с кадра 0), затем `COVER_FADE_FRAMES = 15` — плавный переход в урок.
- Проекты Remotion держат **байт-в-байт копию** в своих `src/components/LessonCover.tsx` (импорт вне папки проекта ломает разрешение `node_modules`). Проверка: `python3 shared/lesson-cover/check_copies.py`.
- `lessons/NNN.json` — номер и проверенная тема каждого урока; **по одному файлу на урок**, чтобы параллельные чаты не конфликтовали.
- Миниатюра YouTube: та же разметка в композиции 1280×720 (компонент масштабируется по размеру композиции) → PNG рядом с MP4.
- Шрифт: проект должен загрузить кириллический Noto Sans 700 (или передать `fontFamily`).

Используют: `production/vid-002/video` (уроки 1–3 = R01–R03). Для 004–005: скопировать файл как есть, добавить `lessons/004.json`, `005.json`.
