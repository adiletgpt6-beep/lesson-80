# Общий аудиопайплайн LESSON-80 (AUDIO_JOIN_QA_RULES.md)

- `clip_clean.py` — очистка каждого TTS-клипа до монтажа: DC, удаление посторонних краевых всплесков ElevenLabs
  (островок ≤160 мс у самого края клипа, отделённый тишиной ≥180 мс), fade 8/15 мс, запас по пику −1,4 dBFS. Длина клипа
  не меняется. Без noise gate. `python3 shared/audio/clip_clean.py in.mp3 out.mp3`.
- `join_qa.py` — блокирующая проверка готового MP4 по списку стыков (`[{key,start,end}]` в секундах): всплески/щелчки,
  скачки в тишине, громкие обрывы, клиппинг, DC, скачки громкости. Выход 1 = публиковать нельзя; подозрительные места
  прослушать.
- Проекты подключают их своими адаптерами (пример: `production/vid-002/scripts/audio_clean_lesson.py`, `audio_joins.py`).
  Для 004–005: прогнать `clip_clean` по своим клипам и `join_qa` по своему таймлайну.
