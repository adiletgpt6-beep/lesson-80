## Метод

1. `TRANSCRIPT_DIR=lessons/VID-003/transcript SOURCE_MANIFEST=lessons/VID-003/source/manifest.json python3 scripts/transcribe_full.py plan|parallel|merge SOURCE`
   — 25 запросов Scribe v2 (`language_code=kir`, `timestamps_granularity=word`), склейка в общих паузах соседних кусков.
2. `python3 production/lesson-006-007/kyrgyz_pass.py SOURCE` — интервалы, записанные казахскими буквами, перераспознаны
   запросами по 150/75/40 с со сдвинутыми границами, пока ответ не придёт кыргызской орфографией.
3. `python3 scripts/audio_crosscheck_mms.py SOURCE --spec … --out recheck/mms` — независимая модель Meta MMS-1B-all с
   кыргызским адаптером (локально, бесплатно) на 29 религиозно значимых интервалах.

## Язык

- Автоопределение Scribe без подсказки: `kaz` (p = 0,72 на 00:00:40, 0,94 на 01:00:00) — но на **одном и том же звуке**
  стыка 00:04:53–00:05:07 первый кусок записан казахскими буквами, второй — чисто кыргызскими («башийбейт», «ардай»,
  «Курандагы», «ошол»). Орфографию Scribe выбирает на весь запрос.
- Meta MMS с кыргызским адаптером читает те же интервалы кыргызскими формами: «эми имандын алты шарты бар… Алла Таала
  бар эле… ага окшош эч нерсе жок…» (M01–M04), «пайгамбардын өмүр баянын… эң илимдүү адам» (M27, M29).
- Вывод: **основной язык урока — кыргызский** (южный говор, с узбекскими/казахскими заимствованиями: «башийбейт»,
  «ардай», «ишениш»); казахская запись — артефакт распознавателя, как и в VID-001. Окончательно язык/говор подтверждает носитель.
