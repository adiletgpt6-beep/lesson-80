## Что нужно выполнить Claude Code дальше

### Этап A. Редакторская версия на кыргызском

1. **Не менять** `transcript/full.kir.md` и сырой API-ответ. Заполнить отдельный `transcript/full.ky.edited.md` с абсолютными таймкодами.

3. Каждый сомнительный смысл сверить с аудио, если Claude Code имеет возможность слушать. *Сгенерированный ASR не является проверкой на слух.* Если достоверной аудиопроверки нет — сохранить статус `unverified`, не выдавать догадку за услышанную речь.

### Этап C. Религиозная достоверность
