# Формат сценария `script/chapters/chNN.json`

Один файл на главу (`ch00`…`ch16`). Это единственный источник текста: из него генерируются читаемый сценарий (`chapters.ky.md`), раскадровка (`storyboard.md`), оценка длительности (`durations.md`), запросы TTS (`scripts/tts_generate.py`) и таймлайн Remotion (`video/src/timeline.json`).

```jsonc
{
  "id": "ch04",
  "title_ky": "Кайдан келдик, кайда барабыз",
  "planned_seconds": 150,              // план из chapters-таблицы; НЕ подтверждённая длительность
  "source_ideas": ["I13", "I14"],      // из analysis/meaning-map-reviewed.csv
  "scenes": [
    {
      "id": "ch04-s01",
      "title_ky": "Үч суроого жооп",
      "setting": "класс, доска",       // фон/локация
      "camera": "орто план: устаз + доска",
      "characters": ["ustaz", "bektur", "aizada"],
      "board": ["Доскада: КАЙДАН? → АЛЛАХТАН", "..."],         // что рисуется/пишется на доске (по порядку)
      "animation": ["Устаз маркер менен жебе тартат", "..."],   // движения персонажей и анимации
      "beats": [
        {"type": "line", "speaker": "ustaz", "text": "…кыргызча…",
         "source": ["I13 00:08:30–00:09:08"],  // таймкоды оригинала; [] только для чисто педагогических реплик
         "ped": false,                          // true = авторское педагогическое добавление (не слова устаза)
         "blocked": null},                      // id из qa-blockers.md (напр. "R1"), если реплика ждёт проверки
        {"type": "pause", "seconds": 3, "reason": "балдар ойлонот"},
        {"type": "visual", "seconds": 4, "description": "анимация без речи"}
      ]
    }
  ]
}
```

Правила:
- `speaker`: `ustaz` | `bektur` | `aizada` | `both_children`.
- `text` — только произносимый текст (без ремарок). Арабские аяты — кириллической транслитерацией; такие реплики обязательно `blocked: "R1"` (сверка по мусхафу и на слух).
- Реплика, опирающаяся на спорный/непроверенный фрагмент, получает `blocked` с id блокера; TTS-скрипт её не озвучивает без `--allow-blocked`.
- Слабые хадисы и безосновательные риваяты не используются вообще (см. `analysis/sources-review.csv`).
- `ped: true` — для всех вымышленных диалогов детей, бытовых примеров-замен и вопросов, не взятых из лекции; если реплика пересказывает мысль устаза в детской форме, `ped: false`, но `source` обязателен.
- Аллах не изображается; пророки (Муса, Харун и др.) не изображаются — только символы на доске.
