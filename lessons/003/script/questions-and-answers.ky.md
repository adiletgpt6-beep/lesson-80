# 3-сабак — балдардын суроолору жана жооптору (долбоор)

**Бул суроолор [ПЕД] — авторлук педагогикалык кошумча.** Булактагы залдан берилген чыныгы суроолор (01:01–01:04) угулбайт жана бул жерге көчүрүлгөн эмес. Жооптор устаздын ойлоруна гана таянат; ар бир жоопто булак (I-номери, убакыт) көрсөтүлгөн. Арабча цитаталар [`../analysis/sources-review.csv`](../analysis/sources-review.csv) боюнча текшерилгенден кийин гана үнгө жазылат.

## Колдонулбай турган суроолор (себеби менен)

- «Каапырга эмне үчүн сооп жазылбайт?» (булактагы I48) — жоопто алсыз хадис бар; 4–12 жаш үчүн кирбейт.
- «Карызды кантип берүү керек?» (I52) — алсыз хадис (Ибн Мажа 2431) + чоңдорго тиешелүү тема; кирбейт.
- Залдан угулбаган суроолор (01:01:11–01:01:52, 01:03:46–01:04:24) — жооптору ойлоп табылбайт.
