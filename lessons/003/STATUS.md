## Альтернативный защищённый доступ без передачи постоянных R2-ключей

Он использует созданный пользователем bucket-scoped read-only токен **локально**; ключи не должны передаваться в чат, GitHub или Claude Code. Ссылка сама является краткоживущим секретом: передавать только в личной сессии Claude Code, не коммитить и не цитировать в логах. После скачивания сверить исходный SHA-256 из манифеста. **Подписанная ссылка и фактическая загрузка через неё пока не подтверждены.**
