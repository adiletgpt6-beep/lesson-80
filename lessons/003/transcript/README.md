Диагностика (≈ $0.007, записана здесь, файлы не сохранены): 60-секундные клипы 00:00 и 02:00 с `kir` тоже дают казахскую орфографию; авто-определение без `kir` — `kaz` p=0,97 (00:00–01:00) и `kir` p=0,76 (05:00–05:45).
В «казахских» интервалах много кыргызских форм (`жашау`, `мейнет`, `азыр`, `аял`, `оору`/«оры», `ушул`/«шұл»), устаз упоминает Бишкек, Ош, Жалал-Абад, Нарын, Талас и спрашивает «Таластар барбы?».
