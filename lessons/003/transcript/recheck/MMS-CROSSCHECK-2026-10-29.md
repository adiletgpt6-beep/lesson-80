# Перекрёстная машинная проверка спорных мест: Meta MMS-1B-all (кыргызский адаптер `kir`)

**Что это:** третье, независимое от ElevenLabs, машинное распознавание коротких клипов локально на CPU (бесплатно). Модель другого семейства (wav2vec2 CTC, без языковой модели, без пунктуации, нижний регистр). Результат может **поддержать или опровергнуть гипотезу**, но **не является прослушиванием человеком**: согласие двух-трёх моделей ≠ подтверждение. `audio_verified` остаётся `false` везде; **ни один блокер не снят.**

- Источник: `/tmp/lesson-003.mp4`, SHA-256 `e042aedc…0ef60876` (сверен перед запуском).
- Модель: `facebook/mms-1b-all` (`model.safetensors` 3 859 521 128 байт, SHA-256 `88d5528f…d329dd`) + `adapter.kir.safetensors`; transformers 5.21.0, torch 2.15.0 (CPU).
- Скрипт: `scripts/audio_crosscheck_mms.py … --model-dir /tmp/mms-model`; сырые результаты — `K*.mms_kir.json`, `B*.mms_kir.json` в этой папке. Аудио в репозиторий не записывалось.
- Проба: K06, 12 с → «…**не деген чоң соодабыла**» — ожидаемая фраза «Не деген чоң соода бул» распознана ⇒ модель работает на этой записи.

Обозначения: **ASR-1** — ElevenLabs Scribe v2 по 5-минутному чанку; **ASR-2** — Scribe v2 по короткому клипу; **MMS** — этот прогон.
