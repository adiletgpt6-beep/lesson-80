# Урок 003 — план пробной озвучки (НЕ ЗАПУЩЕН)

**Статус: подготовлен, не выполнен.** Платный шаг запускается только после двух подтверждений владельца:
1. **Бюджет ElevenLabs** — сколько кредитов можно потратить (остаток аккаунта Claude прочитать не может: у ключа нет права `user_read`).
2. **Оценка голоса T1** — владелец/носитель прослушал 40-секундную пробу на приватной странице и одобрил голоса.

Критические блокеры смысла (B1, B5, B6, R2–R5, R9) пробу **не затрагивают**: выбранные главы их не содержат, а заблокированные реплики скрипт не озвучивает.

## Зачем проба
Оценка длительности строится по темпу 40-секундной пробы. Полный текст: **58:44** при обычной скорости голоса и **1:04:05** при `speed 0.9` (текущая настройка в `voices.json`). Только реальный звук покажет, какая скорость нужна, чтобы получить 60:00 без пустых пауз и без вырезания смысла.

## Шаги

| Шаг | Что | Строк / символов | Оценка кредитов* | Лимит в команде |
|---|---|---|---|---|
| 1 | `ch16` (финал, 0 блокеров) — калибровка темпа и голосов детей | 8 / 368 | ≈180 | `--max-credits 250` |
| 2 | `ch06` (диалоги устаза с детьми, 2 реплики заблокированы и пропускаются) | 38 / 2 818 | ≈1 380 | `--max-credits 1500` |
| **Итого** | | 46 / 3 186 | **≈1 560** | ≤ 1 750 |

\*0,49 кредита/символ — наблюдалось на пробе (276 символов → 134 кредита, заголовок `character-cost`).

```bash
python3 scripts/tts_generate.py --scenes ch16-                                   # сухой прогон: проверить цифры
python3 scripts/tts_generate.py --scenes ch16- --confirm --max-credits 250       # только после подтверждения бюджета
python3 scripts/lesson_script.py timeline                                        # реальные длительности → таймлайн
```
Клипы сохраняются в `lessons/003/audio/clips/` (не в Git); `audio/manifest.json` (длительности, кредиты) коммитится.

## Что измеряем и как решаем
- Реальная длительность каждой реплики vs оценка → поправочный коэффициент для всех глав.
- Если при `speed 0.9` фильм выходит > 60:00 — подобрать скорость 0,92–1,0 (без вырезания мыслей); если < 60:00 — добавить содержательные вопросы и объяснения по теме, а не паузы.
- Носитель оценивает: понятность, ударения, «ң/ө/ү», «Аллах Таала», «алейхиссалам», имена детей.
