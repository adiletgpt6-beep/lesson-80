# Lesson 003 — Remotion project

1920×1080, 30 fps, **no music**. The composition `Lesson003` is the whole film; `Lesson003-chNN` is one chapter with
frame 0 at the chapter start (used for per-chapter renders that are concatenated without re-encoding).
`src/timeline.json` is generated by `python3 scripts/lesson_script.py timeline` from `lessons/003/script/chapters/*.json`
+ `ped-replacements.json` + `ped-extra-beats.json` + real clip durations in `lessons/003/audio/manifest.json`.
Blocked lines never reach the timeline (see `scripts/script_lines.py`).

Art (`src/art/`): `Ustaz.tsx`, `Kid.tsx` — parametric SVG rigs (poses, gestures, blink, mouth driven by speech beats);
`icons.tsx` — marker-style pictograms drawn stroke by stroke; `boardPlans.ts` — what is drawn on the board per scene;
`Cutaway.tsx` + `scenePlan.ts` — full-frame illustrated inserts. Allah and the prophets are never depicted.
Fonts: Noto Sans (cyrillic + cyrillic-ext for ң/ө/ү) in `public/fonts`.

```bash
cd video && npm ci
npm run typecheck
ln -s ../../lessons/003/audio/clips public/audio          # TTS clips (git-ignored)
CHROME=/opt/pw-browsers/chromium-1243/chrome-linux64/chrome
./node_modules/.bin/remotion still src/index.ts Lesson003 out/still.png --frame=300 --browser-executable=$CHROME
./node_modules/.bin/remotion render src/index.ts Lesson003-ch16 out/chapters/ch16.mp4 \
  --browser-executable=$CHROME --concurrency=4 --codec=h264 --crf=20 --jpeg-quality=85 --audio-codec=aac
# all chapters → ffmpeg concat (see lessons/003/render/README.md)
```
Rendering speed in the cloud container: ≈9 frames/s on 4 cores (≈3.3 h for the 59-minute film).
