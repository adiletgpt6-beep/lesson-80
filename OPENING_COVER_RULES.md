# Обязательные обложки уроков LESSON-80

Статус: общее производственное правило для всех новых рендеров уроков 001–080, включая параллельные задачи 001–003 и 004–005.

## Обложка в начале каждого MP4
- С первого кадра (t=0) показывать единую титульную обложку ровно 3,00 секунды (90 кадров при 30 fps), затем плавный переход к содержанию. Не добавлять заставку перед обложкой.
- На обложке обязательно **полный порядковый номер из 80** на кыргызском: «80 САБАКТЫН 1-САБАГЫ», «80 САБАКТЫН 2-САБАГЫ», …, «80 САБАКТЫН 80-САБАГЫ». Это означает «первый урок из восьмидесяти» и т. д. Нельзя писать только «1-САБАК» без общего количества.
- Под номером указывать точную тему соответствующего урока на кыргызском языке, утверждённую по содержанию. Не писать «Жетпей», «Жетбей» или иное название проекта.
- Все 80 обложек имеют один утвержденный шаблон: композиция, фон, цвета, шрифты, размеры, размещение элементов. Меняются только номер и тема. Читабельно на мобильном экране и в уменьшенном превью.
- Тему брать из проверенного содержания и утвержденных метаданных, не придумывать. Учитывать перенумерацию: новые 001–003 из старых 001–002, новые 004–005 из старого 003.
- Создать единый параметризованный компонент Remotion; использовать его в обоих параллельных производственных потоках. Избегать конфликтующих правок в общих файлах; синхронизировать изменения через отдельную ветку/PR.
- При рендере отдельно экспортировать кадр обложки в PNG или JPG 1280×720 (16:9), с тем же оформлением и надписями, для возможной загрузки как YouTube thumbnail. YouTube не обязан автоматически выбрать первый кадр: при необходимости использовать готовый экспорт.
- Проверка качества: первые 90 кадров содержат правильную обложку с номером из 80 и темой, текст без ошибок и не обрезан; переход корректен; длительность урока учитывает эти 3 секунды. Без фоновой музыки.
- Существующие утвержденные MP4 и оригинальные исходники не перезаписывать: новые версии хранить отдельно.
- Прежде чем объявлять урок готовым, проверить обложку и файл миниатюры.

Каждый чат обязан прочитать этот файл в начале следующего рабочего шага и включить правило в свой текущий рендер: чат уроков 001–003 и чат уроков 004–005. Не считать, что один чат автоматически видит изменения другого.
