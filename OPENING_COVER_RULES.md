# Обязательные обложки и названия YouTube для уроков LESSON-80

Статус: постоянное правило для всех 80 уроков, включая параллельные задачи 001–003 и 004–005.

## Три обязательных результата для КАЖДОГО урока
1. Готовый MP4: с первого кадра (t=0) единая титульная заставка ровно 3,00 секунды (90 кадров при 30 fps), затем плавный переход к содержанию.
2. **Отдельный готовый файл обложки для YouTube**, JPG или PNG 1280×720, 16:9, визуально совпадающий с заставкой. Не полагаться на автоматический выбор первого кадра YouTube. Экспортировать файл для каждого урока, даже если заставка уже встроена в видео.
3. **Готовый заголовок YouTube на кыргызском языке**, пригодный для копирования без редактирования. Формат: «80 САБАКТЫН N-САБАГЫ | [Так тема на кыргызском]». Сохранять в отдельном UTF-8 файле рядом с видео (например, lesson-001-youtube-title.txt), а также выводить отдельной строкой в финальном отчёте с удобным копированием. Проверять длину заголовка по ограничению YouTube (не более 100 символов).

## Единое оформление
- На заставке и отдельной обложке обязательно полный порядковый номер из 80: «80 САБАКТЫН 1-САБАГЫ», «80 САБАКТЫН 2-САБАГЫ» и т. д. Под номером точная тема урока на кыргызском языке.
- Не писать «Жетпей», «Жетбей» или другое название проекта.
- Все 80 обложек используют один утверждённый шаблон: фон, композиция, цвета, шрифты, размеры и размещение текста; меняются только номер и тема. Дизайн читается на телефоне и в маленькой миниатюре.
- Тема и заголовок должны соответствовать проверенному содержанию конкретного урока; не выдумывать темы. Учитывать перенумерацию: новые 001–003 из старых 001–002; новые 004–005 из старого 003.
- Использовать единый параметризованный компонент Remotion; согласовывать его между параллельными ветками без конфликтующих изменений.
- Без фоновой музыки. Не добавлять служебные плашки «требует проверки устаза» и другие внутренние статусы (см. FINAL_VIDEO_USTAZ_REVIEW_RULES.md). Проверять аудиосклейки (см. AUDIO_JOIN_QA_RULES.md).
- Финальный QA: проверить первые 90 кадров, читаемость, точность темы, корректность текста и номера из 80, отдельный файл миниатюры, копируемый заголовок, отсутствие служебных надписей. Существующие утверждённые исходники не перезаписывать.

## Доставка
Для каждого урока предоставить три отдельных скачиваемых файла: MP4, JPG/PNG обложки, TXT названия, плюс в отчёте показать заголовок отдельной копируемой строкой. Дать рабочие ссылки на просмотр видео и прямое скачивание каждого файла.

## Для двух текущих чатов Claude Code
Каждый чат обязан прочитать актуальную версию этого файла из main в начале следующего рабочего шага и включить правило в текущий рендер: чат уроков 001–003 и чат уроков 004–005. Не считать, что один чат автоматически видит изменения другого.
